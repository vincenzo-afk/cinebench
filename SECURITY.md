# Security Policy

## Supported Versions

The following versions of CineBench are currently being supported with security updates.

| Version | Supported |
| :--- | :--- |
| 1.x.x | ✅ |
| < 1.0.0 | ❌ |

## Reporting a Vulnerability

We take the security of CineBench seriously. If you believe you have found a security vulnerability, please report it to us by following these steps:

1.  **Do not disclose the vulnerability publicly** until we have had a chance to address it.
2.  **Send an email** to [itsmebk2007@gmail.com](mailto:itsmebk2007@gmail.com) with a detailed description of the vulnerability.
3.  Include steps to reproduce the issue and any potential impact.

We will acknowledge receipt of your report and provide a timeline for addressing the issue. Thank you for helping keep CineBench secure!
